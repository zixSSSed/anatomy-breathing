# Дыхательная система

Сайт для подготовки к зачёту по анатомии и физиологии человека, темы 4.1 и 4.2:
дыхательные пути, лёгкие, плевра, физиология дыхания.

Что есть:

- 3D-модель гортани, трахеи, бронхиального дерева, долей лёгких, плевры и диафрагмы с режимом «Дышать» и проверкой «Найди на модели»
- полный конспект обеих лекций с поиском и отметками о прочитанном
- раздел «Лекции»: оригинальный текст обеих лекций целиком и файлы Word для скачивания (собирается из `src/lectures/*.docx` скриптом `docx2html.py`)
- интерактивные схемы: носовые ходы и пазухи, гортань, бронхиальное дерево, границы лёгких и плевры, возрастные изменения
- физиология: анимация вдоха и выдоха, спирограмма с калькулятором ЖЕЛ и МОД, аэрогематический барьер, транспорт газов, регуляция
- 140 тестовых вопросов с пояснениями, 112 карточек, тренажёры, 36 билетов с таймером, словарь на 84 термина
- прогресс хранится в браузере

## Как открыть

Готовый сайт лежит в папке `docs`. Откройте `docs/index.html` в браузере или включите GitHub Pages
(Settings → Pages → Deploy from a branch → `main`, папка `/docs`).

## Как менять

Страницы собираются из `src/pages/*.html` и общего шаблона в `build.py`:

```
python build.py
```

Стили и скрипты лежат прямо в `docs/assets`. Вопросы теста — `src/data-quiz.js`,
карточки, словарь, тренажёры и билеты — `src/data-study.js`.

Источники: конспекты тем 4.1 и 4.2; И. В. Гайворонский, М. Р. Сапин, А. А. Швырёв «Анатомия и физиология человека».
