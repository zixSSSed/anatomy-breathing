# Дыхательная система

Сайт-приложение для подготовки к зачёту по анатомии и физиологии человека, темы 4.1 и 4.2:
дыхательные пути, лёгкие, плевра, физиология дыхания.

**Открыть:** https://zixsssed.github.io/anatomy-breathing/

Что есть:

- 3D-модель гортани, трахеи, бронхиального дерева, долей лёгких, плевры и диафрагмы с режимом «Дышать» и проверкой «Найди на модели»
- полный конспект обеих лекций с поиском и отметками о прочитанном, 16 рисунков из анатомических атласов
- раздел «Лекции»: оригинальный текст обеих лекций целиком и файлы Word для скачивания
- интерактивные схемы: носовые ходы и пазухи, гортань, бронхиальное дерево, границы лёгких и плевры, возрастные изменения, атлас рисунков
- физиология: анимация вдоха и выдоха, живая альвеола с газообменом, спирограмма с калькулятором ЖЕЛ и МОД, регуляция
- 140 тестовых вопросов с пояснениями, 112 карточек со свайпами, тренажёры, 36 билетов с таймером, словарь на 84 термина
- поиск по всему сайту (Ctrl K или «/»), прогресс по темам, серия дней и календарь занятий

## На iPhone

Откройте сайт в Safari, нажмите «Поделиться» → «На экран „Домой“». Сайт откроется как приложение
(своя иконка, без адресной строки, нижняя панель вкладок) и после первого открытия работает без интернета.
В «Настройках» можно выбрать тему, включить «Жидкое стекло» в стиле iOS 26 и уменьшить анимации.

## Как устроено

Приложение на React 18 + Vite, анимации — Motion, 3D — three.js.

```
app/                  React-приложение
  src/pages/          страницы (главная, тест, карточки, тренажёры, билеты, словарь, прогресс)
  src/components/     оболочка, поиск, общие компоненты
  src/legacy/         модули схем, физиологии, 3D-модели и иллюстраций
  src/generated/      собирается из src/ скриптом build.py — руками не править
  public/             иконки, манифест, файлы лекций
src/pages/*.html      тексты конспекта, схем, физиологии, лекций
src/data-*.js         вопросы теста, карточки, словарь, тренажёры, билеты
src/lectures/*.docx   оригиналы лекций (из них собирается раздел «Лекции»)
build.py, atlas.py, docx2html.py   подготовка содержимого
sw.template.js        шаблон офлайн-кэша
docs/                 готовый сайт для GitHub Pages (собирается командой ниже)
```

## Как собрать

Нужны Node.js 18+ и Python 3.

```
cd app
npm install
npm run build      # содержимое → React → docs/
npm run dev        # локальная разработка: http://localhost:5173
```

GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/docs`.
Иконки приложения перерисовывает `python make_icons.py` (нужен Pillow).

Источники: конспекты тем 4.1 и 4.2; И. В. Гайворонский, М. Р. Сапин, А. А. Швырёв «Анатомия и физиология человека».
Рисунки — Wikimedia Commons, авторы и лицензии указаны под каждым рисунком.
